# Security

When reporting or investigating security issues in Kestrel, include the Kestrel version, `herdr-core` (`kc --version`) version, OS, reproduction steps, and impact. Remove any secrets, GCP service account keys, or personal data from logs.

For how Kestrel handles local mods, `herdr-core` sockets, and privacy, see [docs/security.md](docs/security.md).
